# Spec Delta

## MODIFIED Requirements

### Requirement: 月の合計を勤怠行から返す

システムは、指定したダミー社員と実在する `YYYY-MM` の年月について、その月の保存済み勤怠行だけを材料に合計を返さなければならない（SHALL）。保存済みでない日と、行に無い値を、合計の材料に足してはならない（MUST NOT）。

#### Scenario: 通常出勤は休憩を引いた実働になる

- **GIVEN** 通常出勤で出勤 09:00、退勤 18:00、休憩 01:00 の行が1件ある
- **WHEN** その月の合計を要求する
- **THEN** その行の実働は 8 時間である
- **AND** 8時間を超えた分は 0 である

#### Scenario: 8時間を超えた分だけを残業とする

- **GIVEN** 通常出勤で、休憩を引いた実働が 9 時間の行が1件ある
- **WHEN** その月の合計を要求する
- **THEN** その行は出勤日数に含まれる
- **AND** 8時間を超えた分は 1 時間である

#### Scenario: 退勤が無い日は実働に足さない

- **GIVEN** 通常出勤で退勤が無い行が1件ある
- **WHEN** その月の合計を要求する
- **THEN** 退勤が無い日の件数に 1 足す
- **AND** その行の実働は総実働に足さない

#### Scenario: 欠勤は出勤日数に入れない

- **GIVEN** 欠勤の行が1件ある
- **WHEN** その月の合計を要求する
- **THEN** その行は出勤日数に含まれない
- **AND** その行の実働は総実働に足さない

#### Scenario: 保存済みでない日は合計を変えない

- **GIVEN** 社員1の 2026-11 には、保存済みでない日がある
- **WHEN** 更新する前に、社員1の 2026-11 の合計を要求する
- **THEN** 出勤日数は 18 である
- **AND** 総実働は 137 時間である
- **AND** 8時間を超えた分は 1 時間である
- **AND** 退勤が無い日の件数は 1 である

#### Scenario: 行が無い月の合計はゼロ

- **GIVEN** 社員1の 2026-02 には保存済みの行が無い
- **WHEN** 社員1の 2026-02 の合計を要求する
- **THEN** 出勤日数は 0 である
- **AND** 総実働は 0 である
- **AND** 8時間を超えた分は 0 である
- **AND** 退勤が無い日の件数は 0 である

#### Scenario: 保存した時刻で合計が変わる

- **GIVEN** 社員1の 2026-11-02 が、通常出勤、出勤 09:00、退勤 19:00、休憩 01:00 に更新されている
- **WHEN** 同じ実行環境で 2026-11 の合計を要求する
- **THEN** 出勤日数は 18 である
- **AND** 総実働は 138 時間である
- **AND** 8時間を超えた分は 2 時間である

### Requirement: 合計も不正な指定では返さない

勤怠行を返さない指定では、システムは合計も返してはならない（MUST NOT）。

#### Scenario: 年月が不正なら合計も返さない

- **GIVEN** 社員はダミーにいる
- **WHEN** 年月に `2026/11` を指定して合計を要求する
- **THEN** 合計は返さない

#### Scenario: 月が13なら合計も返さない

- **GIVEN** 社員はダミーにいる
- **WHEN** 年月に `2026-13` を指定して合計を要求する
- **THEN** 合計は返さない
