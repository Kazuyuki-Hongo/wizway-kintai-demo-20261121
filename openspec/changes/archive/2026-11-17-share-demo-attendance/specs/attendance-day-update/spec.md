# Spec Delta

## MODIFIED Requirements

### Requirement: 保存できない指定では更新しない

年月が `YYYY-MM` でないとき、月が 01 から 12 でないとき、社員がダミーに無いとき、または日付がその月に無いとき、システムは更新を成立させてはならない（MUST NOT）。その月の空の日は、条件を満たす更新で行を作らなければならない（SHALL）。年月が不正なときは、理由をログに1行残さなければならない（SHALL）。

#### Scenario: 年月の形が違う

- **GIVEN** 社員1の 2026-11-02 が保存済みである
- **WHEN** 年月 `2026/11` で、その日を更新しようとする
- **THEN** 更新は成立しない
- **AND** その日の値は変わらない
- **AND** ログに、年月が不正である理由が1行残る

#### Scenario: 月が13

- **GIVEN** 社員1がダミーにいる
- **WHEN** 年月 `2026-13` で更新しようとする
- **THEN** 更新は成立しない
- **AND** ログに、年月が不正である理由が1行残る

#### Scenario: 社員がダミーに無い

- **GIVEN** 指定した識別子のダミー社員が無い
- **WHEN** 年月 `2026-11` の 2026-11-02 を更新しようとする
- **THEN** 更新は成立しない

#### Scenario: 日付がその月に無い

- **GIVEN** 社員1がダミーにいる
- **WHEN** 年月 `2026-11` の 2026-11-31 を更新しようとする
- **THEN** 更新は成立しない

#### Scenario: 空の日を保存すると行ができ、他の社員は残る

- **GIVEN** 社員1の 2026-11-21 は保存済みでなく、社員2の 2026-11-02 は保存済みである
- **WHEN** 社員1の 2026-11-21 を通常出勤、出勤 09:00、退勤 18:00、休憩 01:00 に更新する
- **THEN** 2026-11-21 は保存済みになる
- **AND** 社員2の 2026-11-02 の出勤は 09:00、退勤は 18:00 のままである
