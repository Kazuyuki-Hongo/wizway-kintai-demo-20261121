# 設計

## 前提

動機は proposal.md の「なぜ」。管理者の表示名とパスワード、左メニューの2項目は proposal.md のスコープにある。

リポジトリは `wizway-kintai-demo`。画面は `frontend/`。API は `backend/app.py`。表は `sql/schema.sql` と `sql/seed.sql`。ログインとセッションは実装済みで、`add-demo-login` として残っている。公開中の共有ファイルは、学習用アカウントの非公開 S3 にある `attendance.db`。

実装に入る前に、Serena MCP（namespace は `user-serena`）で `initial_instructions` を呼ぶ。失敗したらコードを編集しない。手順の正本は `.cursor/skills/openspec-apply-change/SKILL.md`。Serena の詳細は `docs/rules/project-rules-serena.md`。

適用の前に、`add-demo-login` を正本へ反映してアーカイブする。先にこの変更を反映すると、ログイン後の最初の画面が3人の合計に戻る。

## 目標 / 対象外

**目標:**
- ログイン直後の画面を、その人の 2026-11 の日ごとにする
- 左に「自分の勤怠」を置き、管理者だけ「全員の勤怠」を足す
- 既存の勤怠行を残したまま、デモ管理を1人足す

**対象外:**
- 勤怠の3人のどれかを管理者にすること
- メニュー項目を2つより増やすこと

## 決定事項

### 1. 管理者は社員の列で持つ

`employees` に `is_admin` を足す。勤怠の3人は 0、デモ管理は 1。パスワードは今と同じ PBKDF2-HMAC-SHA256 で、`sql/build_db.py` が `kanri` のハッシュを入れる。平文は `sql/seed.sql` に書かない。

開いた共有ファイルにデモ管理がいないときは、勤怠行を残したまま1人足し、ハッシュを入れる。失敗したら書き戻さない。

### 2. 自分以外は API で止める

セッションの社員が管理者でないとき、自分以外の月、合計、全員の合計、CSV、日の更新は 403 にする。`reason` は「全員の勤怠は管理者だけが見られます」。行も記録も書かない。

管理者の全員の合計は、`is_admin` が 0 の3人だけを返す。デモ管理の自分の月は、行が無い月と同じく、各日が空で合計は 0 である。

社員一覧は、管理者には勤怠の3人、本人には自分だけを返す。

### 3. 画面は左メニューを先に置く

ログイン後の領域を、左メニューと本文に分ける。本文の初期表示は自分の月である。「自分の勤怠」で自分の月に戻る。管理者の「全員の勤怠」は、今の3人の合計である。そこから「日ごとを入力」で、その人の日ごとへ移る。CSV のボタンは、全員の勤怠にだけ出す。

ログイン画面の表に、デモ管理と `kanri` の行を足す。

### 4. デプロイは学習用アカウントだけ

プロファイル `deploy-jisseki` で、アカウントが `655129713987` であることを確認してから `sam deploy` する。プロファイル `deploy` と、アカウント `023194178508` は使わない。スタック名は `wizway-kintai-demo`。画面は既存のフロント用バケットへ出す。公開 URL が変わっていなければ、学習パックの導入メモとコース本文は編集しない。

`openspec/specs/attendance-overview/spec.md` の Purpose は、全員の合計を管理者の「全員の勤怠」で読む文に直す。差分仕様では Purpose を変えられない。

## リスク / トレードオフ

- [社員2が社員1を更新する既存テスト] → その更新はデモ管理で行う。社員2の更新は拒否を確認する
- [共有ファイルに管理者がいない] → 開いたときに1人足す。勤怠の3人の行は消さない

## 移行手順

1. `add-demo-login` を正本へ反映してアーカイブする
2. 管理者の追加、本人以外の拒否、左メニューを足し、pytest と Playwright で確認する
3. `attendance-overview` の Purpose を、管理者の「全員の勤怠」で読む文に直す
4. アカウントを確認してから、学習用アカウントの API と画面を更新する
5. 公開 URL が変わっていないことを確認する。変わっていなければ導入メモは更新しない
6. 戻すときは、直前の関数と画面の成果物に戻す。共有ファイルの管理者の行は残してよい
