# Spec Delta

## MODIFIED Requirements

### Requirement: ダミー社員だけを一覧する

システムは、ログインしたセッションがあるとき、用意したダミー社員の識別子と表示名だけを返さなければならない（SHALL）。管理者のセッションでは、勤怠の対象である3人を返さなければならない（SHALL）。管理者自身を、この一覧に含めてはならない（MUST NOT）。管理者でないセッションでは、ログインした本人だけを返さなければならない（SHALL）。実在の社員、給与、住所、生年月日を含めてはならない（MUST NOT）。

#### Scenario: 一覧は識別子と表示名だけ

- **GIVEN** 勤怠の対象が3人、管理者が1人用意されている
- **WHEN** デモ管理でログインし、社員一覧を要求する
- **THEN** 勤怠の3人の識別子と表示名が返る
- **AND** デモ管理は含まれない
- **AND** 給与、住所、生年月日は含まれない

#### Scenario: 本人には本人だけが返る

- **GIVEN** サンプル海原でログインしている
- **WHEN** 社員一覧を要求する
- **THEN** 返るのはサンプル海原だけである
- **AND** 給与、住所、生年月日は含まれない
