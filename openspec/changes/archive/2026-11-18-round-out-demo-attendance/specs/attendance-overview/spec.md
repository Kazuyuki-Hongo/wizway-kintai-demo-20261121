# Spec Delta

## ADDED Requirements

### Requirement: 有休にすると一覧の出勤日数が減る

一覧の合計は、その人の月合計と同じ式でなければならない（SHALL）。有休にした日は出勤日数と実働から外れ、他の社員の合計は変わってはならない（MUST NOT）。

#### Scenario: 社員1の1日を有休にしても他の2人は変わらない

- **GIVEN** 2026-11 の全員の合計が初期データのままである
- **WHEN** 社員1の 2026-11-02 を有休にし、出勤、退勤、休憩を空にしてから、2026-11 の全員の合計を要求する
- **THEN** 社員1の出勤日数は 17 である
- **AND** 社員1の総実働は 129 時間である
- **AND** 社員1の8時間を超えた分は 1 時間である
- **AND** 社員1の退勤が無い日の件数は 1 である
- **AND** 社員2の出勤日数は 19、総実働は 152 時間、8時間を超えた分は 0、退勤が無い日の件数は 0 である
- **AND** 社員3の出勤日数は 19、総実働は 144 時間、8時間を超えた分は 0、退勤が無い日の件数は 1 である

## MODIFIED Requirements

### Requirement: 一覧から日ごとの入力へ移る

システムは、指定月の全員の合計を最初の画面に出さなければならない（SHALL）。各行の操作は「日ごとを入力」とし、表示名をボタンの文に含めてはならない（MUST NOT）。その操作で、その人と月の日ごとの入力を出さなければならない（SHALL）。一覧の画面では、その月の行を保存できてはならない（MUST NOT）。

#### Scenario: 最初の画面は3人の合計である

- **GIVEN** 画面を開いた
- **WHEN** 月が 2026-11 である
- **THEN** 3人の表示名と、それぞれの出勤日数、総実働、8時間を超えた分、退勤が無い日の件数が見える
- **AND** 各行に「日ごとを入力」がある
- **AND** その画面に、日を保存する操作は無い

#### Scenario: 行を選ぶと日ごとの入力になる

- **GIVEN** 2026-11 の全員の合計が見えている
- **WHEN** 社員2の行で「日ごとを入力」を押す
- **THEN** 社員2の 2026-11 の日ごとの入力が見える
- **AND** 2026-11-02 の出勤は 09:00、退勤は 18:00 である
