# Spec Delta

## Purpose

指定した月について、ダミー社員全員の出勤日数、総実働、8時間を超えた分、退勤が無い日の件数を1画面で返す。行を選ぶと、その人の日ごとの入力へ移る。

## ADDED Requirements

### Requirement: 指定月の全員の合計を返す

システムは、ログインなしで、実在する `YYYY-MM` の年月について、用意したダミー社員全員の識別子、表示名、その月の合計を返さなければならない（SHALL）。合計は、その人の保存済み勤怠行だけを材料にした出勤日数、総実働、8時間を超えた分、退勤が無い日の件数でなければならない（SHALL）。給与、住所、生年月日を含めてはならない（MUST NOT）。この読み取りだけで行を追加、更新、削除してはならない（MUST NOT）。

#### Scenario: 3人の識別子と表示名と合計が返る

- **GIVEN** ダミー社員が3人用意されている
- **WHEN** 2026-11 の全員の合計を要求する
- **THEN** 3人の識別子と表示名が返る
- **AND** 各人に、出勤日数、総実働、8時間を超えた分、退勤が無い日の件数が付く
- **AND** 給与、住所、生年月日は含まれない

### Requirement: 初期データの合計を人数ごとに返す

2026-11 の初期データでは、システムは各人の保存済み行から計算した合計を返さなければならない（SHALL）。

#### Scenario: 社員1は欠勤と退勤なしを含む

- **GIVEN** 社員1の 2026-11 が初期データのままである
- **WHEN** 2026-11 の全員の合計を要求する
- **THEN** 社員1の出勤日数は 18 である
- **AND** 総実働は 137 時間である
- **AND** 8時間を超えた分は 1 時間である
- **AND** 退勤が無い日の件数は 1 である

#### Scenario: 社員2は全日が通常の8時間である

- **GIVEN** 社員2の 2026-11 が初期データのままである
- **WHEN** 2026-11 の全員の合計を要求する
- **THEN** 社員2の出勤日数は 19 である
- **AND** 総実働は 152 時間である
- **AND** 8時間を超えた分は 0 である
- **AND** 退勤が無い日の件数は 0 である

#### Scenario: 社員3は退勤なしがある

- **GIVEN** 社員3の 2026-11 が初期データのままである
- **WHEN** 2026-11 の全員の合計を要求する
- **THEN** 社員3の出勤日数は 19 である
- **AND** 総実働は 144 時間である
- **AND** 8時間を超えた分は 0 である
- **AND** 退勤が無い日の件数は 1 である

### Requirement: 行が無い月は各人ゼロで返す

保存済みの行が無い月でも、システムはダミー社員全員を返し、各人の合計をゼロにしなければならない（SHALL）。

#### Scenario: 2026-02 は3人ともゼロ

- **GIVEN** 2026-02 には、どのダミー社員にも保存済みの行が無い
- **WHEN** 2026-02 の全員の合計を要求する
- **THEN** 3人が返る
- **AND** 各人の出勤日数、総実働、8時間を超えた分、退勤が無い日の件数は 0 である

### Requirement: 不正な年月では一覧を返さない

年月が `YYYY-MM` でないとき、または月が 01 から 12 でないとき、システムは全員の合計を返してはならない（MUST NOT）。理由をログに1行残さなければならない（SHALL）。

#### Scenario: 年月の形が違う

- **GIVEN** ダミー社員が用意されている
- **WHEN** 年月に `2026/11` を指定して全員の合計を要求する
- **THEN** 一覧は返らない
- **AND** ログに、年月が不正である理由が1行残る

#### Scenario: 月が13

- **GIVEN** ダミー社員が用意されている
- **WHEN** 年月に `2026-13` を指定して全員の合計を要求する
- **THEN** 一覧は返らない
- **AND** ログに、年月が不正である理由が1行残る

### Requirement: 一覧から日ごとの入力へ移る

システムは、指定月の全員の合計を最初の画面に出さなければならない（SHALL）。行を選ぶと、その人と月の日ごとの入力を出さなければならない（SHALL）。一覧の画面では、その月の行を保存できてはならない（MUST NOT）。

#### Scenario: 最初の画面は3人の合計である

- **GIVEN** 画面を開いた
- **WHEN** 月が 2026-11 である
- **THEN** 3人の表示名と、それぞれの出勤日数、総実働、8時間を超えた分、退勤が無い日の件数が見える
- **AND** その画面に、日を保存する操作は無い

#### Scenario: 行を選ぶと日ごとの入力になる

- **GIVEN** 2026-11 の全員の合計が見えている
- **WHEN** 社員2の行を選ぶ
- **THEN** 社員2の 2026-11 の日ごとの入力が見える
- **AND** 2026-11-02 の出勤は 09:00、退勤は 18:00 である
