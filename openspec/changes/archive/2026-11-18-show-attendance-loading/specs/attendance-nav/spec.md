# Spec Delta

## ADDED Requirements

### Requirement: 行が届くまで読み込んでいますと出す

今選んでいる月の日ごと、または全員の合計がまだ画面に無いあいだ、画面は「読み込んでいます」と出さなければならない（SHALL）。そのあいだ、日の保存はできてはならない（MUST NOT）。左メニューは見えなければならない（SHALL）。届いたら「読み込んでいます」は消えなければならない（SHALL）。

#### Scenario: サンプル海原の自分の月が届くまで

- **GIVEN** ログイン画面を開いている
- **WHEN** サンプル海原を `unahara` でログインし、2026-11 の日ごとがまだ出ていない
- **THEN** 「読み込んでいます」が見える
- **AND** 「自分の勤怠」が見える
- **AND** 日を保存する操作はできない

#### Scenario: 届いたら消える

- **GIVEN** サンプル海原でログインしている
- **WHEN** 2026-11 の日ごとが画面に出る
- **THEN** 「読み込んでいます」は見えない
- **AND** 2026-11-02 の出勤は 09:00、退勤は 18:00 である

#### Scenario: 月を変えているあいだは保存できない

- **GIVEN** サンプル海原の 2026-11 の日ごとが見えている
- **WHEN** 月を 2026-12 に変え、12月の日ごとがまだ出ていない
- **THEN** 「読み込んでいます」が見える
- **AND** 2026-11-02 を保存する操作はできない

#### Scenario: デモ管理の全員の勤怠が届くまで

- **GIVEN** デモ管理でログインしている
- **WHEN** 「全員の勤怠」を押し、2026-11 の3人の合計がまだ出ていない
- **THEN** 「読み込んでいます」が見える
- **AND** 「全員の勤怠」が見える
