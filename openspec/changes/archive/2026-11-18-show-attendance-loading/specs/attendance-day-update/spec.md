# Spec Delta

## ADDED Requirements

### Requirement: 保存の通信中は待っていると出す

その日の保存を送っているあいだ、画面はその日について「保存しています」と出さなければならない（SHALL）。そのあいだ、同じ日の保存を重ねて送ってはならない（MUST NOT）。成立するまで「保存しました」を出してはならない（MUST NOT）。通信が終わったら「保存しています」は消えなければならない（SHALL）。拒否されたときは、今の日本語の理由を出さなければならない（SHALL）。

#### Scenario: 通信中は保存しています

- **GIVEN** テスト青空でログインし、自分の 2026-11-02 の出勤は 09:00、退勤は 18:00 である
- **WHEN** 退勤を 19:00 にして保存し、応答がまだ返っていない
- **THEN** 「保存しています」が見える
- **AND** 「保存しました」は見えない
- **AND** その日の保存をもう一度押しても、更新は増えない

#### Scenario: 成立すると保存しましたに替わる

- **GIVEN** テスト青空の 2026-11-02 は退勤 18:00 である
- **WHEN** 退勤を 19:00 にして保存し、応答が返る
- **THEN** 「保存しています」は見えない
- **AND** 「保存しました」が見える
- **AND** その日の退勤は 19:00 である

#### Scenario: 退勤が出勤より前だと保存しましたは出ない

- **GIVEN** テスト青空の 2026-11-02 は出勤 09:00、退勤 18:00 である
- **WHEN** 退勤を 08:00 にして保存し、応答が返る
- **THEN** 「保存しています」は見えない
- **AND** 「保存しました」は見えない
- **AND** 画面に、退勤は出勤より前にはできない、と出る
- **AND** その日の退勤は 18:00 のままである
