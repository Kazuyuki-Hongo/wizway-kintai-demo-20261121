# Spec Delta

## ADDED Requirements

### Requirement: CSVを出しているあいだは待っていると出す

CSV を出しているあいだ、画面は「出しています」と出さなければならない（SHALL）。そのあいだ、同じ月の CSV を重ねて出してはならない（MUST NOT）。ファイルが届いたら「出しています」は消えなければならない（SHALL）。失敗したときは、出せなかったと出し、もう一度出せるようにしなければならない（SHALL）。

#### Scenario: 通信中は出しています

- **GIVEN** デモ管理が 2026-11 の全員の合計を見ている
- **WHEN** この月の CSV を出し、ファイルがまだ届いていない
- **THEN** 「出しています」が見える
- **AND** もう一度押しても、CSV の通信は増えない

#### Scenario: 届いたら消える

- **GIVEN** デモ管理が 2026-11 の全員の合計を見ている
- **WHEN** この月の CSV が届く
- **THEN** 「出しています」は見えない
- **AND** ファイル名は `kintai-2026-11.csv` である
