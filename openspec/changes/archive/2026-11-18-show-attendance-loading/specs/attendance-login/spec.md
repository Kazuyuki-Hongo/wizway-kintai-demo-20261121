# Spec Delta

## ADDED Requirements

### Requirement: ログインの通信中は待っていると出す

ログインを送っているあいだ、画面は「ログインしています」と出さなければならない（SHALL）。そのあいだ、同じログインを重ねて送ってはならない（MUST NOT）。通信が終わったら、その文は消さなければならない（SHALL）。失敗したときは、今の理由を出し、ログインを再度送れるようにしなければならない（SHALL）。

#### Scenario: 通信中はログインしています

- **GIVEN** ログイン画面を開いている
- **WHEN** サンプル海原を `unahara` でログインし、応答がまだ返っていない
- **THEN** 「ログインしています」が見える
- **AND** ログインをもう一度送っても、通信は増えない

#### Scenario: パスワードが違うとログインに戻る

- **GIVEN** ログイン画面を開いている
- **WHEN** サンプル海原に、違うパスワードを入れてログインし、応答が返る
- **THEN** 「ログインしています」は見えない
- **AND** 画面に、社員名かパスワードが違う、と出る
