# Spec Delta

## MODIFIED Requirements

### Requirement: ダミー社員だけを一覧する

システムは、ログインしたセッションがあるとき、用意したダミー社員の識別子と表示名だけを返さなければならない（SHALL）。実在の社員、給与、住所、生年月日を含めてはならない（MUST NOT）。

#### Scenario: 一覧は識別子と表示名だけ

- **GIVEN** ダミー社員が3人用意されている
- **WHEN** 社員一覧を要求する
- **THEN** 3人の識別子と表示名が返る
- **AND** 給与、住所、生年月日は含まれない
