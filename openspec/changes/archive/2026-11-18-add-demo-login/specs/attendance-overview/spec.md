# Spec Delta

## MODIFIED Requirements

### Requirement: 指定月の全員の合計を返す

システムは、ログインしたセッションがあるとき、実在する `YYYY-MM` の年月について、用意したダミー社員全員の識別子、表示名、その月の合計を返さなければならない（SHALL）。合計は、その人の保存済み勤怠行だけを材料にした出勤日数、総実働、8時間を超えた分、退勤が無い日の件数でなければならない（SHALL）。給与、住所、生年月日を含めてはならない（MUST NOT）。この読み取りだけで行を追加、更新、削除してはならない（MUST NOT）。

#### Scenario: 3人の識別子と表示名と合計が返る

- **GIVEN** ダミー社員が3人用意されている
- **WHEN** 2026-11 の全員の合計を要求する
- **THEN** 3人の識別子と表示名が返る
- **AND** 各人に、出勤日数、総実働、8時間を超えた分、退勤が無い日の件数が付く
- **AND** 給与、住所、生年月日は含まれない
