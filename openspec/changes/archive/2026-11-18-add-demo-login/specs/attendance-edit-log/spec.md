# Spec Delta

## MODIFIED Requirements

### Requirement: 成立した保存を1件残す

保存が成立したとき、システムは記録を1件足さなければならない（SHALL）。記録は、入力者、対象の社員、日付、変更前の区分と出勤と退勤と休憩、変更後の区分と出勤と退勤と休憩を含まなければならない（SHALL）。入力者は、ログインした社員でなければならない（SHALL）。給与、住所、生年月日を含めてはならない（MUST NOT）。

#### Scenario: 別の社員が有休に変える

- **GIVEN** 社員1の 2026-11-02 は通常出勤、出勤 09:00、退勤 18:00、休憩 01:00 である
- **AND** その日の記録は無い
- **WHEN** 社員2でログインして、その日を有休、出勤、退勤、休憩を空にして更新する
- **THEN** その日の記録が1件ある
- **AND** 入力者は社員2である
- **AND** 対象は社員1である
- **AND** 日付は 2026-11-02 である
- **AND** 変更前は通常出勤、出勤 09:00、退勤 18:00、休憩 01:00 である
- **AND** 変更後は有休で、出勤、退勤、休憩は空である

#### Scenario: 空の日の保存は変更前が空である

- **GIVEN** 社員1の 2026-11-21 は保存済みでない
- **WHEN** 社員1でログインして、その日を通常出勤、出勤 09:00、退勤 18:00、休憩 01:00 に更新する
- **THEN** その日の記録が1件ある
- **AND** 変更前の区分と時刻は空である
- **AND** 変更後は通常出勤、出勤 09:00、退勤 18:00、休憩 01:00 である

## ADDED Requirements

### Requirement: 記録の入力者はログインした社員である

ログインしたセッションがあるとき、更新に入力者が無くても、システムは更新を成立させなければならない（SHALL）。記録の入力者は、送られた入力者ではなく、ログインした社員でなければならない（SHALL）。

#### Scenario: 入力者を送らない

- **GIVEN** 社員1の 2026-11-02 が保存済みである
- **WHEN** 社員1でログインし、入力者を送らず、その日を通常出勤、出勤 10:00、退勤 19:00、休憩 01:00 に更新する
- **THEN** 更新は成立する
- **AND** その記録の入力者は社員1である

#### Scenario: 送った入力者は使わない

- **GIVEN** 社員1の 2026-11-02 が保存済みである
- **WHEN** 社員2でログインし、入力者を社員3にして、その日を通常出勤、出勤 10:00、退勤 19:00、休憩 01:00 に更新する
- **THEN** 更新は成立する
- **AND** その記録の入力者は社員2である

## REMOVED Requirements

### Requirement: 入力者が無い更新は対象の社員として残す

**Reason**: 入力者は対象の社員ではなく、ログインした社員になる
**Migration**: ログインしてから保存する。送った入力者は記録に使わない
