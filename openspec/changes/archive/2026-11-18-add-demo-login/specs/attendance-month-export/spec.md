# Spec Delta

## MODIFIED Requirements

### Requirement: 指定月の全日を CSV で返す

システムは、ログインしたセッションがあるとき、実在する `YYYY-MM` の年月について、ダミー社員3人のその月の各日を CSV で返さなければならない（SHALL）。列は社員名、日付、区分、出勤、退勤、休憩である（SHALL）。行は社員1、社員2、社員3の順で、各人は日付の昇順である（SHALL）。文字コードは UTF-8 で、先頭に BOM を付けなければならない（SHALL）。給与、住所、生年月日を含めてはならない（MUST NOT）。この読み取りだけで行を追加、更新、削除してはならない（MUST NOT）。

#### Scenario: 2026-11 は保存済みと空の日を含む

- **GIVEN** 2026-11 が初期データのままである
- **WHEN** 2026-11 の CSV を要求する
- **THEN** 見出しの次の行数は 90 である
- **AND** テスト青空の 2026-11-01 は、区分、出勤、退勤、休憩が空である
- **AND** テスト青空の 2026-11-02 は通常出勤、出勤 09:00、退勤 18:00、休憩 01:00 である
- **AND** テスト青空の 2026-11-05 は欠勤で、出勤、退勤、休憩は空である
- **AND** 見本山辺の 2026-11-02 は通常出勤、出勤 10:00、退勤 19:00、休憩 01:00 である
- **AND** 見本山辺の 2026-11-04 は通常出勤、出勤があり、退勤は空である
- **AND** 給与の列は無い
- **AND** テスト青空の 2026-11-02 の出勤は 09:00 のままである

#### Scenario: 行が無い月は区分と時刻が空

- **GIVEN** 2026-02 には、どのダミー社員にも保存済みの行が無い
- **WHEN** 2026-02 の CSV を要求する
- **THEN** 見出しの次の行数は 84 である
- **AND** 各行の区分、出勤、退勤、休憩は空である
