# Proposal

## Why

勤怠の画面は、開いた人が誰でも3人の行を読めて保存できる。入力者は画面で選ぶだけで、パスワードもセッションも無い。デモでも、普通のシステムなら最初にログインがある。

## 背景

ダミー社員は3人。一覧は3人の合計が先に出て、「日ごとを入力」でその人の日ごとへ移る。保存が成立すると、選んだ入力者が記録に残る。入力者を選ばないと保存できない。API はログインなしで読み取りと更新を受ける。現行仕様の `attendance-month` と `attendance-overview` は、ログインなしで返すと書いている。

## 目的

ダミー3人それぞれにパスワードを置き、ログインしてから一覧と保存を使えるようにする。一覧は3人のまま残す。保存の入力者は、ログインした人にする。入力者の選択は画面から外す。

## What Changes

- 開いた画面はログイン。正しいパスワードのときだけ、いまの一覧へ進む
- ログイン画面に、3人の表示名とパスワードを書く。API の応答にはパスワードを含めない
- **BREAKING** セッションが無い読み取りと更新は成立しない。行も記録も変えない
- **BREAKING** 更新に別の入力者を送っても、記録の入力者はログインした人になる。入力者が無い更新を、対象の社員として成立させることはやめる
- 入力者を選ぶ操作と、「入力者を選んでください」は出さない
- ログイン中の表示名と、ログアウトを出す。ログアウトするとログイン画面に戻る

## Capabilities

### New Capabilities

- `attendance-login`: ダミー3人のパスワードでログインし、セッションが無い操作を拒否し、ログアウトできる

### Modified Capabilities

- `attendance-month`: 社員一覧と月の行は、ログインしたセッションがあるとき返す
- `attendance-overview`: 全員の合計は、ログインしたセッションがあるとき返す
- `attendance-day-update`: 入力者未選択では保存しない、という要件を外す。保存できたあとの入力者はログインした人である
- `attendance-edit-log`: 記録の入力者はログインした人である。入力者を送らなくても、ログインしていればその人として残る
- `attendance-month-export`: CSV は、ログインしたセッションがあるとき返す

## スコープ

- パスワードは次の3組。ログイン画面に同じ組を出す
  - テスト青空 `aozora`
  - サンプル海原 `unahara`
  - 見本山辺 `yamabe`
- パスワードが違うとき、または表示名がダミーに無いときは、ログインできない。社員名とパスワードのどちらが違ったかは出さない
- ログインしたあとも、3人の合計一覧と、選んだ人の日ごとの入力は今のまま使える
- 保存の記録に残る入力者は、ログインした社員である
- ログアウトすると、そのセッションでは一覧も保存もできない
- 本番勤怠リポジトリと本番 AWS アカウントは変更しない。デプロイ先は学習用アカウントのみ

## 非スコープ

- パスワードの変更、再設定、メール、連続失敗でのロック
- 権限の差。3人とも、ログインすれば同じ一覧を見られる
- ログインした人の行だけに画面を絞ること
- 外部の認証サービス、本番のアカウント、SSO
- DynamoDB、RDS、コンテナの常時起動
- 実在の社員名、給与、住所、生年月日
- 学習パックのコース本文。公開 URL が変わらない限り導入メモも更新しない

## リスク

- 既存のテストはログインなしで API を呼んでいる。セッションを付けるまで失敗する
- 共有ファイルは保存もログインも同じ1ファイルへ書く。重なると、後の書き込みがファイルごと残る
- ログイン画面にパスワードを出すので、このデモのパスワードは秘密ではない

## Impact

- `sql/schema.sql` のパスワードとセッション、`sql/seed.sql`、共有ファイルを開いたときの拡張
- `backend/app.py` のログイン、ログアウト、セッション確認、入力者の決定
- `template.yaml` のログインとログアウト
- `frontend/src/App.tsx` のログイン画面と、入力者の選択を外すこと
- `backend/tests` と `tests/e2e/attendance.spec.ts`
- 学習用アカウント `655129713987` のスタック `wizway-kintai-demo` と画面。本番アカウントには出さない
