# Proposal

## Why

保存が拒否されたとき、画面に英語の理由がそのまま出る。休憩を入れても、長さではなく時刻として読むと「長すぎる」になる。

## 背景

API は拒否理由を英語の短いコードで返す。画面はその文字列をそのまま出す。休憩は `HH:MM` の長さで、出勤や退勤と同じ時刻ではない。

## 目的

保存できないとき、画面のメッセージを日本語にする。休憩が長すぎるときは、長さであることと、1時間なら `01:00` であることを書く。

## What Changes

- 画面は、既知の拒否理由を日本語の文に置き換えて出す
- API が返す理由のコードと、ログの英語は変えない

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `attendance-day-update`: 保存が拒否されたとき、画面に日本語の説明を出す

## スコープ

- 画面に出る保存失敗の文だけ
- 本番勤怠リポジトリと、本番の勤怠と同じ AWS アカウントは変えない

## 非スコープ

- 休憩を時刻として受け付けること
- 拒否の条件を緩めること
- DynamoDB、RDS

## リスク

- 画面の対応表に無い理由は、英語のまま残る。対応表に今の理由をすべて入れる

## Impact

- `frontend/src/App.tsx`、Playwright
- API の `reason` は変えない
